# Markdown 转 HTML 功能演示

这是自动 Markdown 转 HTML 功能的演示文章。本文章将展示如何使用此功能来创建博客内容。

## 功能特点

1. **自动转换** - 提交 Markdown 文件后，GitHub Actions 会自动将其转换为 HTML
2. **样式统一** - 转换后的页面与网站其他页面保持一致的样式
3. **代码高亮** - 支持代码语法高亮显示
4. **响应式设计** - 在各种设备上都能良好显示

## 代码示例

以下是一些代码示例：

```javascript
// JavaScript 示例
function helloWorld() {
  console.log('Hello, World!');
  return true;
}
```

```python
# Python 示例
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

print(fibonacci(10))
```

```html
<!-- HTML 示例 -->
<div class="container">
  <h1>欢迎来到我的网站</h1>
  <p>这是一个段落示例。</p>
</div>
```
