## 一句话结论

2026 年 11 月 2 日，MIT CSAIL 的 DSPy 一作 Omar Khattab 团队发了一篇博客，主张通用 LLM 可以**像读代码一样读、改、写另一个神经网络的权重**——不过优化器、不过梯度、不写训练循环。

结论是：**这件事有一半是真的，但被标题夸大了两倍。** 局部故障修复、万级参数网络的零样本编写，已被多个独立团队复现；而"读懂权重语义"在严谨审计下更像是"局部算术 + 数据集先验"，标签一换就穿帮。

## 它到底主张什么

Weight-Space Programming（WSP）的定义很直接：把权重张量当作程序文本，LLM 根据自然语言目标直接编辑它。

作者自己加了两个限定，值得先记住：

- **natively** 指"由 LLM 自己推理决定改什么"，不是调用一个专门训练的权重读写模型；Python 只是推理工具，部分实验完全不给工具，部分只允许有限次前向；
- **WSP 是"能力火花"，不是方法**。类比 GPT-3 展示 in-context learning——证明能力存在，不宣称打败微调或 RL。

主角模型是 GPT-6 Astra，目标网络从 17,253 个参数的小 MLP，一直到 0.8B 的 Qwen3.5-0.8B。

## 三类实验：读、修、写

### 读：它能看到什么

| 实验 | 设置 | 结果 |
|---|---|---|
| 猜游戏 | 4 个 PPO 训练的网格游戏策略，17,253 个权重以纯文本给出，无工具 | 4/4 全对，依据是第一层权重的空间分布 |
| 猜扩散模型 | 3 个 DDPM，23,824 个权重，禁止前向 | 3/3 全对；把实心形状读成"轮廓"，说明读的是几何而非模拟前向 |
| 只给中间层猜语言 | 7.2M 字符级 transformer，删掉输入输出层 | 3/3 全对，并精确找出全部 induction heads |
| 找谄媚模型 | 诚实版 vs 谄媚版 Gemma 3 270M | **纯权重 4 次全败**；允许看注意力模式后 3/3 |

最后一行是整篇博客最重要的边界：**权重的稠密中间语义，目前读不动。** 能读的是结构性的、低维的、与几何强相关的信息。

### 修：改 3.5% 的权重，成功率从 0 到 100%

Kinetix 赛车爬坡任务，PPO 训了 10 亿步陷入局部最优——它不会先倒车助跑。给全部 171,664 个权重、场景描述和一段录像，模型单次回复改了 **6,073 个权重（3.5%）**，成功率 **0% → 100%**（1,024 episodes），而且改出来的是一条可读的小通路："先倒车，越过红带后关闭"。

更受关注的是 Qwen3.5-0.8B 的数学能力：

- 定位到第 15/19 层 MLP 写出的"思考死循环方向"，从每层 64 个输出列中减去该方向；
- 共改 **131,072 个权重（0.016%）**；
- MATH-500 **7.9% → 48.1%**，GSM8K 13.8% → 67.1%，IFEval 21.0% → 62.3%；
- 截断率 93% → 33.1%。

同一套流程用在 Gemma 3 270M 上**完全失败**（6.8% → 最高 7.7%），因为那个模型没有循环病理，错误是普通算术错误。作者自己的总结很准确：**编辑权重能移除挡住能力的障碍，但不能凭空添加模型没有的能力。**

### 写：零数据、零梯度地"编译"一个网络

- MinAtar 游戏：给规则和游戏源码，从全零网络一次写出全部权重，Breakout 得分 **517.4**，对比 PPO-100M 步的 15.8、PPO-500M 步的 25.3；
- 9×9 围棋：1,480,274 个权重，击败同规模、训了 2000 万局的 PPO 网络。

这两项最像"程序合成"：不是学出来的，是把"算球落点 → 移挡板"这样的过程直接编译进权重。

## 三个必须打折扣的地方

**第一，"读语义"很大程度靠记忆。**

BRAC University 的审计论文（arXiv 2611.08070）用 Claude Opus 5.5、无工具、无前向地读 5 个数据集训练的小 CNN。结论是零样本"读权重"更像**局部算术 + 数据集先验**：

- 局部计算很准，能从 BatchNorm 统计推断出约 3 步 Adam 更新；
- 但语义靠模板套：KMNIST 认成 MNIST，99.57% 准确率的 SAT-6 卫星图网络被读成"CIFAR-10 动物照片"；
- **标签置换对照**是关键——输出分组结构找对了，9 对类名全错。这说明类名来自记住的 CIFAR-10 标签顺序，不是从权重推出来的。

注意这篇的边界：它**不否定**原博客的编辑与写入结果，只审计"读"的机制。

**第二，头条数字是"修复病理"，不是"注入能力"。**

7.9% 的基线是病态采样：93% 的答案因死循环被截断。579 个被救回的答案里，576 个原本就是截断输出；原本能正常完成的题目，正确率没变。也就是说，它修的是"卡死"，不是"不会数学"。这一点原博客自己披露了，但传播时被标题吃掉了。

**第三，证据面很窄。**

全部结果来自单一 LLM、目标网络不超过 0.8B、博客未经同行评审。弱基线的批评成立（Go 基线 MLP 太弱、Qwen 基线被病理污染），虽然作者回应说这是"给零经验写网络定价"，不是刷榜。

## 复现生态：这才是它真正的分量

一个博客能在两周内引出上百项复现，说明它触到了真问题。

| 工作 | 结果 |
|---|---|
| Simon Willison 本地复现 | 用笔记本上的 Qwen 27B，3/4 正确（每题 46 分钟到 1 小时、4 万+ 推理 token）；能力不专属于 GPT-6 |
| Hugging Face 复现 | 重建编辑版 checkpoint，独立重跑 MATH-500 得 **51.0%**，模型与演示空间开源 |
| arXiv 2611.09382 系统评测 | 16 条编辑轨迹 × 7 个基准：MATH-500 最高 **+29.45pp（只改 1,023 个参数）**、IFEval +36.72、SciBench +17.11；但 **16 条里 6 条因无法可靠验证提升而保留原权重** |
| IWIBench | 首个"梯度无关的模型驱动权重内注入"agentic 基准 |
| Physics2Weight（2611.12954） | 把 WSP 扩展到解 PDE，误差低于 PINN，但非线性 PDE 的物理一致性仍不足 |
| Snowflake-Labs | 企业侧复现仓库，在 Snowflake 上让 LLM 修网络 |

**"6/16 放弃"是最该被引用的数字**——它说明干预点的发现是可靠的瓶颈，而不是随便改改就能涨分。

## 技术谱系：新在哪，不新在哪

| 路线 | 代表 | 与 WSP 的差别 |
|---|---|---|
| 机制可解释性 | Distill Circuits、ROME/MEMIT、单方向拒绝消融 | 人类研究者 + 专用工具；WSP 的新意是通用 LLM 零样本自发组合这些技术 |
| 训练出来的权重读取器 | Weight Oracles（2610.07334，NeurIPS workshop） | 微调专用模型读权重，后门检测 AUROC 0.93；与"原生能力"互补 |
| 超网络 / 模型生成权重 | HyperNetworks、p-diff、NeuroGen | 需要专门训练或搜索；WSP 主张免训练、推理驱动 |
| 无梯度优化 | SPSA、ES、MeZO | 仍靠试错；WSP 靠语义推理定位干预点 |
| LLM 优化文本制品 | OPRO → DSPy/MIPRO → GEPA → autoresearch | WSP 把"推理驱动优化"推进到可微网络本体 |

一句话：**技术组件大多不新，新的是"前沿 LLM 不用教就会用它们"。**

## 怎么判断一条 WSP 声明可不可信

看完这些材料，我整理了一份检查清单，比记住任何一个数字都有用：

1. **基线有没有被病理污染**——截断率、超时率是多少？提升是"救回卡死"还是"学会解题"？
2. **有没有随机方向对照**——改一个随机方向涨多少？原博客里这个数是 +1.6，这才是真实效应量；
3. **有没有层隔离对照**——改第 15 层有效，改第 3 层呢？没有层间对照，就不知道是定位还是碰巧；
4. **有没有报告放弃的轨迹**——16 条里放弃 6 条，和不提这 6 条，是两个结论；
5. **有没有做标签置换**——"读"类实验不做置换，就无法排除记忆；
6. **换模型还成不成立**——单模型结果只能算 existence proof。

## 我的判断

**真的部分**：权重确实可以作为文本制品被 LLM 分析；高度局部化的单因故障修复效果惊人且已独立复现；万级参数网络可以零样本一次写成。这三条足够支撑"这是一项真实的新兴能力"。

**要打折的部分**：语义读取依赖数据集记忆；头条提升主要是修故障；可靠性（16 条里 6 条失败）和验证方法都还没解决；"递归自我改进"的解读证据不足——连批评者都承认它 impressive，但"改进训练"短期仍是正道。

**值得做的方向**：权重级安全审计（后门检测、篡改检测）、免数据的定向修复与 unlearning、跨架构的电路移植。这三件事都有明确的工程价值，而且不依赖"LLM 真的读懂了权重"这个强主张。
