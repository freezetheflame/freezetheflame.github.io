# Lint Workflow

## Goal

Keep the wiki useful as it grows.

## Checks

- Broken wiki links.
- Pages missing from `wiki/index.md`.
- Pages missing from `app/wiki-data.js`.
- Repeated claims that should be merged.
- Claims that need source notes.
- Pages that cover more than one concept.

## Suggested Cadence

Run a lint pass after every few ingests, or before using the wiki for a high-stakes answer.
