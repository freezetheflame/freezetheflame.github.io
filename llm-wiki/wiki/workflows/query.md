# Query Workflow

## Goal

Answer questions from the wiki first, then improve the wiki when the answer teaches something durable.

## Steps

- Start at `wiki/index.md`.
- Search page titles, tags, and text in the browser app.
- Read only the pages needed to answer.
- If evidence is missing, inspect `raw/` or search externally when current information is required.
- If the final answer is reusable, update a page or create one.
- Append notable updates to `wiki/log.md`.

## Done Means

- The user gets an answer.
- Future sessions can recover the durable part without repeating the whole conversation.
