# Compilation Over Retrieval

## Summary

Retrieval finds relevant source fragments at question time. Compilation turns source fragments and prior answers into stable pages before the next question arrives.

## Why It Matters

A wiki can accumulate judgment. The next agent does not need to repeat every source read if the previous agent already distilled the durable parts into clear pages with links and source notes.

## Key Details

- Retrieval is still useful for finding raw evidence.
- Compilation is useful for preserving synthesis, terminology, and decisions.
- The compiled layer should stay small enough to browse.
- A page should cite or name sources when claims are not obvious.
