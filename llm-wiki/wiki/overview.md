# Overview

## Summary

This vault is a compiled knowledge base for LLM-related material. The goal is not to store every token ever read. The goal is to turn useful source material into stable pages that are easy to search, cite, and improve.

## Shape

- `raw/` stores source material.
- `wiki/` stores synthesis.
- `wiki/index.md` is the navigation root.
- `wiki/log.md` records durable changes.
- `app/` renders the wiki in a local browser.

## Operating Principle

The wiki should become better after use. If a question forces a useful synthesis, that answer should usually become a page or update an existing page.
