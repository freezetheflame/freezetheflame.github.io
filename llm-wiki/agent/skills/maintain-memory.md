# Skill: Maintain Memory

## Purpose

Keep long-term project memory useful across machines and future agent sessions.

## Rules

- Store shared project memory in `agent/memory/`.
- Store private or local-only memory in `.wiki-agent/`.
- Convert repeated observations into `agent/memory/concepts.md`.
- Convert durable workflow choices into `agent/memory/decisions.md`.
- Convert unresolved design questions into `agent/memory/open-questions.md`.
- Record ingested sources in `agent/memory/source-ledger.md`.
