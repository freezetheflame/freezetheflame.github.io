# Skill: Synthesize Page

## Purpose

Create or update a wiki page so it is useful without the original conversation.

## Page Shape

- Summary
- Why it matters
- Key details
- Practical implications
- Related pages
- Sources

## Quality Checks

- The page names uncertainty and source limits.
- The page links to nearby concepts.
- The page is not a transcript.
- The page can be found from `wiki/index.md` or search.
