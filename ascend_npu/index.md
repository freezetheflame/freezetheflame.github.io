# 华为Ascend NPU深度学习开发指南

欢迎来到华为Ascend NPU深度学习开发指南。本指南将帮助您了解和使用华为Ascend NPU进行深度学习开发。

## 概述

华为Ascend NPU（Neural Processing Unit）是华为自研的AI处理器，专为深度学习和高性能计算设计。Ascend系列包括Ascend 310、Ascend 910等不同型号，适用于边缘计算和数据中心等不同场景。
